# 城堡战争（试做）

造兵营，兵营自动一个个出兵，上下两路对推，推倒对面主堡获胜。单局目标 9~10 分钟。以电脑（Steam）为第一目标。

- 打开 index.html 即可玩；加 `?debug` 底栏多一个“+1000 金”按钮；加 `?auto&f=tribe|dark` 让电脑替你打（看平衡用）。
- **阵营**：绿皮部落（数量、冲锋）、黑气教团（黑气层数持续掉血+减速，死后留黑气云，怨灵能飞过大海；全是哥布林素材，黑气由代码绘制）。
- **骨架（第 1 批）**：16:9 画布；主堡 4 级（升级花钱，换来生命、箭塔、收入、人口上限）；1 级两个兵营都给，之后每升一级二选一；每种兵营最多 3 座（大怪 1 座，金库 2 座）、同种越造越贵、建造 8 秒、可升级两次、可停产/拆除；人口上限 30/35/40/45；每方 14 个对称格子；主堡在路塔倒下前只受 30% 伤害。
- 抽卡（2:00 / 4:30 / 7:00）只出强化、技能和稀有卡；最多 2 个主动技能；9:30 起加时。
- 数值与卡牌都在 `src/data.js`；引擎在 `src/castle.js`；整体设计见 `docs/DESIGN.md`。地图由 `tools/build_castle_map.py` 生成。
- 还没做：集结技能、推塔强化、中路据点、飞行兵（绿皮部落）、护甲克制、关卡链、Steam 桌面外壳。
