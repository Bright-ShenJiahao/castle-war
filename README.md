# 城堡战争（试做）

造兵营，兵营自动出兵，上下两路对推，推倒对面主堡获胜。单局目标 9~10 分钟。

- 打开 index.html 即可玩；加 `?debug` 底栏多一个“+1000 金”按钮；加 `?auto&f=tribe|dark` 让电脑替你打（看平衡用）。
- **两个阵营**：绿皮部落（数量、冲锋）、黑气教团（黑气层数持续掉血+减速，死后留黑气云，怨灵能飞过大海；全是哥布林素材，黑气全由代码绘制）。
- **局内**：开局三选一建筑卡 → 2:00 / 4:30 / 7:00 定时三选一（建筑 / 强化 / 主动技能，最多 2 个技能）→ 8:30 起加时，血量低的主堡持续崩塌。
- 所有数值和卡牌都在 `src/data.js`；引擎在 `src/castle.js`。设计稿见 `docs/DESIGN.md`（肉鸽关卡链、局外成长还没做）。
- 地图由 `tools/build_castle_map.py` 生成。素材来自《异世界幸存者》项目，版权见 LICENSE。
